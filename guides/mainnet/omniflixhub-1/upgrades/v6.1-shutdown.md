# `Mainnet v6.1  Software Upgrade (Shutting down)`

**Name**: `v6.1`

**When**: The upgrade is scheduled for block `21488000`. (approximately at - `Jan 27th 2026 Friday 13:00 UTC`)

**Details** :

   This upgrade introduces a node panic to ensure a coordinated chain shutdown at block height 21488000.



### Go version

go v1.24.3+

### 1. Manual Method
Wait for Omniflixhub to reach the upgrade height (`21488000`)

Look for a panic message, followed by endless peer logs. Stop the daemon
```
sudo systemctl stop omniflixhubd.service
```

Install go v1.24.3+
```
# Remove previous installation
sudo rm -rf /usr/local/go
wget -q -O - https://git.io/vQhTU | bash -s -- --remove
wget -q -O - https://git.io/vQhTU | bash -s -- --version 1.24.3

# Check version
go version
```

Run the following commands:

```
cd $HOME/omniflixhub
git fetch --all
git checkout v6.1
make install
```
Check Version
```
omniflixhubd version --long
```
output should be
```
build_tags: netgo,ledger
commit: 75d964eb5772b70b70e214592e300f32ae376322
cosmos_sdk_version: v0.50.13
go: go version go1.24.3 linux/amd64
name: OmniFlixHub
server_name: omniflixhubd
version: v6.1

```
Update the service file to prevent automatic restarts on panic.
```bash
# Edit the service file
sudo nano /etc/systemd/system/omniflixhubd.service

# Find the line starting with Restart= and change it to:
Restart=no
# If the line does not exist, add it under the [Service] section.
```
Reload the systemd daemon to apply changes.
```bash
sudo systemctl daemon-reload
```
Restart the omniflixhubd service

```
sudo systemctl start omniflixhubd.service
```

### 2. Cosmovisior Method
#### Install and setup cosmovisor if you haven't running with cosmovisor

  [cosmovisor-setup.md](https://github.com/OmniFlix/docs/blob/main/guides/mainnet/omniflixhub-1/cosmovisor-setup.md)


#### Build and Copy Binary

```bash
git checkout main && git pull
git checkout v6.1
make build && make install

# check the version - should be v6.1
$HOME/go/bin/omniflixhubd version --long
build_tags: netgo,ledger
commit: 75d964eb5772b70b70e214592e300f32ae376322
cosmos_sdk_version: v0.50.13
go: go version go1.24.3 linux/amd64
name: OmniFlixHub
server_name: omniflixhubd
version: v6.1

# make a dir if you haven't
mkdir -p $HOME/.omniflixhub/cosmovisor/upgrades/v6.1/bin

# if you are using cosmovisor you then need to copy this new binary
cp $HOME/go/bin/omniflixhubd $HOME/.omniflixhub/cosmovisor/upgrades/v6.1/bin

# check new version you are about to run - should be equal to v6.1
$HOME/.omniflixhub/cosmovisor/upgrades/v6.1/bin/omniflixhubd version
```
